GOOD TO KNOW

Quick answers.

Does it work on a 2 GB RAM PC?

The launcher is designed to be lightweight, but the game needs memory too. A 2 GB system may struggle to run Minecraft, especially with newer versions or mods. Actual performance varies by hardware and settings.

Does mod search work without a URL?

Yes. The Mods section searches Modrinth directly and installs compatible mod files. You need to choose Fabric, Forge, or NeoForge first; Vanilla does not load mods.

Is the Windows installer available?

Yes. Download the Windows installer from the release link below.

Does a local account provide premium access?

No. A local profile is an offline launcher profile and does not authenticate a Minecraft purchase or provide Microsoft account features.
